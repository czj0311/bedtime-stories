# 晚安故事 · 专属睡前录音

一个只属于两个人的睡前小故事应用。录音、播放、助眠白噪音、定时关闭，全部在手机本地完成，无需注册、无需服务器、录音不上传。

## 在线地址

https://czj0311.github.io/bedtime-stories/

## 安装到手机桌面（像 App 一样使用）

首次打开后，用浏览器自带的“添加到主屏幕 / 安装应用”，即可获得独立图标、全屏启动、离线可用。

### 安卓（华为 / 小米 / OPPO / vivo 等）
用 Chrome 或系统浏览器打开网址 → 右上角菜单 ⋮ → 选择「添加到主屏幕」或「安装应用」。

### 鸿蒙（HarmonyOS）
用华为浏览器打开网址 → 底部菜单（四个点）→ 「添加到桌面」/「添加至主屏幕」。

### 苹果 iPhone / iPad（iOS）
必须用 Safari 打开网址（其他浏览器不行）→ 点底部“分享”按钮 → 「添加到主屏幕」→ 右上角「添加」。

## 主要功能

- 点金色按钮录制睡前故事，支持暂停 / 继续，结束后命名、写留言、保存
- 故事库：收藏、搜索、随机播放、连播、断点续播、倍速、下载备份、删除
- 助眠白噪音：雨声 / 海浪 / 夜风，可调节音量
- 自定义定时：15 / 30 / 60 分钟或自己填 1–600 分钟，到点自动停止并进入“晚安”休眠
- 安装后离线可用，录音保存在本机浏览器（IndexedDB）

## 重要说明

- 录音仅存在本机浏览器，清理浏览器数据会删除，建议常用“下载”备份
- 网页无法真正强制退出 App，定时到点会停止所有声音并显示全屏“晚安”休眠画面，点屏唤醒
- iOS 录音格式为 m4a，安卓 / 鸿蒙为 webm，均正常

## 技术

纯前端 PWA（HTML + CSS + 原生 JS），MediaRecorder 录音、IndexedDB 存储、Web Audio 合成白噪音、Service Worker 离线缓存，通过 GitHub Pages 部署。
