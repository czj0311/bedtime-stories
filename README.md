# 晚安故事 · 专属睡前录音（双人加密同步版）

一个只属于两个人的睡前小故事应用。录音、播放、助眠白噪音、定时关闭全部保留；新增「双人空间」：两台手机各自登录后，故事端到端加密同步，云端只见密文。

## 在线地址

https://czj0311.github.io/bedtime-stories/

## 安装到手机桌面（像 App 一样使用）

首次打开后，用浏览器自带的“添加到主屏幕 / 安装应用”，即可获得独立图标、全屏启动、离线可用。

### 安卓（华为 / 小米 / OPPO / vivo 等）
用 Chrome 或系统浏览器打开网址 → 右上角菜单 ⋮ → 选择「添加到主屏幕」或「安装应用」。

### 鸿蒙（HarmonyOS）
用华为浏览器打开网址 → 底部菜单（四个点）→ 「添加到桌面」/「添加至主屏幕」。

### 苹果 iPhone / iPad（iOS）
必须用 Safari 打开网址（其他浏览器不行）→ 点底部“分享”按钮 → 「添加到主屏幕」→ 右上角「添加」。

## 主要功能

- 点金色按钮录制睡前故事，支持暂停 / 继续，结束后命名、写留言、保存
- 录音统一编码为 MP3（44.1kHz 单声道 64kbps），小米 / 华为 / 苹果三端互相可播
- 故事库：全部 / 我的 / 她的 / 收藏 四种筛选，搜索、随机播放、连播、断点续播、倍速、下载备份、删除
- 助眠白噪音：雨声 / 海浪 / 夜风，可调节音量
- 自定义定时：15 / 30 / 60 分钟或自己填 1–600 分钟，到点自动停止并进入“晚安”休眠
- 双人空间（可选）：邮箱账号 + 邀请码绑定，故事与录音全部端到端加密后同步，断网自动补传
- 安装后离线可用；未开启双人同步时，一切照旧只存本机（IndexedDB）

## 开启双人加密同步（可选）

见 **docs/SUPABASE_SETUP.md**。步骤概要：注册 Supabase（免费档）→ 执行 `supabase/schema.sql` → 把项目地址和 anon key 填进 `js/config.js` → 部署 → 两人各自注册邮箱账号 → 一方创建空间（设置恢复短语）→ 另一方凭邀请码 + 口令加入。

## 重要说明

- 端到端加密：恢复短语只此一份，遗忘后云端内容无法找回（本机副本不受影响）；请把它记在安全的地方，建议纸质抄写两人各存一份
- 密钥只在页面运行时驻留内存；离开页面超过 10 分钟自动锁定，重新输入短语解锁
- 云端免费档约 1GB 音频空间，足够存约 200 个十分钟的加密故事；长期不用时注意项目可能休眠
- 网页无法真正强制退出 App，定时到点会停止所有声音并显示全屏“晚安”休眠画面，点屏唤醒
- iOS 切后台 / 锁屏时网页任务可能被暂停：录音和上传时请保持页面在前台

## 开发

```bash
npm install        # 安装 supabase-js / lamejs / esbuild
npm run build      # 重新打包 vendor/runtime.js（浏览器离线运行库）
npm test           # 加密 / 重采样单元测试
npm run check      # 引用完整性、密钥卫生、构建产物自检
```

代码结构：`js/1-…-10-` 为原有本机功能；`js/11-crypto.js` 端到端加密、`js/12-cloud.js` 云端同步层、`js/13-account.js` 双人空间界面；`supabase/schema.sql` 数据库与权限脚本；`vendor/runtime.js` 为打包产物（勿手改）。

## 技术

纯前端 PWA（HTML + CSS + 原生 JS）：ScriptProcessorNode + lamejs MP3 编码、WebCrypto AES-GCM 端到端加密、IndexedDB 存储、Web Audio 合成白噪音、Service Worker 离线缓存、Supabase（Auth / Postgres RLS / Realtime / 私有 Storage）云端同步，通过 GitHub Pages 部署。
