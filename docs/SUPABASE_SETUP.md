# 开启双人加密同步：Supabase 接入指南

本指南面向项目主人（你们自己）。全程约 30 分钟，不需要付费、不需要域名备案，也不需要你自建服务器。

> 为什么选 Supabase：免费档包含用户登录、数据库、实时同步和 1GB 私密文件存储，够两个人用；它是国际服务，不要求国内实名，网页端直接用（和微信小程序的 18 岁注册门槛、域名备案要求无关）。

## 第 0 步：准备

- 一台电脑（手机也行，但电脑更顺手）
- 两个人的邮箱（各自一个，用来注册 App 内账号）

## 第 1 步：注册 Supabase（免费）

1. 打开 <https://supabase.com> → 点 `Start your project` → 用邮箱注册一个 Supabase 账号（这是你们项目的管理员账号，别告诉她密码也行——但她要知情）。
2. `New project`：名字随便（如 `bedtime`），数据库密码设一个能记住的（存好，比如放进备忘录），地区选 **Northeast Asia (Tokyo)** 或 **Southeast Asia (Singapore)**（离国内近，延迟低）。
3. 等约 2 分钟，项目状态变成绿色 Ready。

## 第 2 步：执行数据库脚本（一次就好）

1. 左侧栏点 **SQL Editor** → `New query`。
2. 用记事本打开本项目的 `supabase/schema.sql`，**全选复制**，粘贴进查询框。
3. 点 **Run**（执行）。看到 `Success. No rows returned` 即成功。
4. 这一步建好了：双人空间表、故事表、每人独立的收藏/进度表、私有音频桶、以及只允许你们俩访问的行级安全策略（RLS）。

## 第 3 步：关闭邮箱验证门槛（建议）

默认注册要等确认邮件，国内邮箱有时收不到。建议关掉：

`Authentication` → `Providers` → `Email` → 关闭 `Confirm email` → Save。

（也可以开着：注册后去邮箱点确认链接，再回来登录，一样能用。）

## 第 4 步：拿到两串“钥匙”

`Project Settings`（齿轮）→ `API Keys`（新版控制台；也可直接访问
`https://supabase.com/dashboard/project/<你的项目ID>/settings/api-keys`）：

- **Project URL**：形如 `https://abcd1234.supabase.co`
- **公开密钥**，两种任选其一，本项目都支持：
  - 新版 **Publishable key**：`sb_publishable_...` 开头（推荐）；首次使用若显示 `Create new API keys`，点一下生成。
  - 旧版 **anon key**：在 `Legacy anon, service_role API keys` 标签页里，`eyJ...` 开头。
  - 项目页右上角的 **Connect** 弹窗里也能直接看到这两样。

⚠️ 只用这两样。**`sb_secret_...` / `service_role` 开头的密钥永远不要填进网页或发给任何人**——它绕过所有权限检查，泄露等于把整个库交出去。

## 第 5 步：填配置并部署

1. 打开本项目 `js/config.js`，把两个空字符串填上：

```js
const BedtimeConfig = {
  SUPABASE_URL: 'https://abcd1234.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGciOi...'
};
```

1. 提交并部署到 GitHub Pages（和平时更新网站一样）。
2. 手机上重新打开网址；如果之前安装过，先刷新一次网页版让缓存更新（或等几小时自动更新）。

## 第 6 步：你们俩绑定

两台手机各自打开 App → 点右上角齿轮（双人空间设置）：

**她先创建（或你先，谁创建都行）：**

1. 点「注册账号」：输入自己的邮箱和登录密码（这只是账号密码，不加密故事）。
2. 登录后选「创建我们的空间」：
   - 输入**恢复短语**：这是加密所有故事的钥匙，**当面告诉她**，别走微信/QQ（聊天记录里留下钥匙就失去了端到端加密的意义）。
   - 短语建议：4 个以上随机词，比如「灯塔 柠檬 骆驼 雪夜 磁带」，12 个字符以上。
3. 创建成功后会显示**邀请码**（48 位，7 天内有效），同样当面给她。

**她加入：**

1. 同样注册/登录自己的账号。
2. 输入邀请码 + 你告诉她的恢复短语 → 加入成功。

之后，顶部出现同步状态徽章；你录的故事会自动加密上传，她的手机几秒内就能听到。

## 第 7 步：验证加密真的生效（可选但建议）

- Supabase 控制台 → `Table Editor` → `stories`：`content_cipher` 列只有乱码密文，`Storage` → `story-audio` 里的音频文件下载下来也打不开（是密文）。✅ 这就是“云端只见密文”。
- 用第三个测试账号登录 → 什么故事都看不到（RLS 拒绝）。✅

## 日常使用要点

- **恢复短语丢失 = 云端内容无法解密**。请两人各自抄一份放安全的地方（纸质更稳）。
- 离线录音：没网也能录和保存，恢复网络后自动补传（列表上显示“待同步”角标）。
- 删除故事：本机删了，联网后云端同步删除，她那边也会消失。
- 免费档说明：闲置约一周项目可能自动暂停（进控制台点 Restore 即可恢复）；1GB 空间约 200 个十分钟的加密故事，用超了删些旧的即可。
- 本机 IndexedDB 的数据永远是你的主副本；浏览器“清除站点数据”会清掉它，重要故事记得「下载」备份。

## 常见问题

**Q：执行脚本时报 `42501: must be owner of table objects`？**  
旧版脚本含有一句对 Supabase 系统表 `storage.objects` 的 `alter table`，平台自 2025 年 4 月起禁止此操作。新版脚本已删掉该行（那张表的行级安全本就默认开启）。重新完整粘贴执行新版 `supabase/schema.sql` 即可——脚本可重复执行，不会产生重复数据。

**Q：打开双人空间显示「当前为仅本机模式」？**  
config.js 没填或没部署成功。回第 5 步检查。

**Q：她说“恢复短语不正确”？**  
短语必须和你创建时输入的**完全一致**（区分空格）。确认不了就只能重置整个空间（云端数据清空重来）：在 SQL Editor 依次执行  
`delete from story_states;` `delete from stories;` `delete from couple_members;` `delete from couples;`  
再到 Storage → `story-audio` → 全选删除残留音频。然后两人重新登录走创建/加入流程。本机数据不受影响。

**Q：想换更强 / 更弱的恢复短语？**  
同上：重置空间后重新创建。云端旧密文会一并清掉。

**Q：收不到确认邮件？**  
回第 3 步关闭邮箱验证，或换邮箱再试。

**Q：录音上传时提示保持前台？**  
iOS 对后台网页限制严格，上传几十秒的录音一般没问题；上传大文件时尽量让页面开着。
